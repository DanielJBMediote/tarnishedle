# Tarnishedle

Um projeto simples usando Vite/Typescript para mm jogo inspirado em Wordle para descobrir armas de *Elden Ring*. A cada rodada, uma arma é escolhida aleatoriamente e você deve encontrá-la usando as pistas reveladas em cada tentativa.

## Funcionalidades

- Busca por nome de arma com sugestões.
- Comparação de tipo, atributos, elementos, efeitos e origem.
- Pontuação baseada no número de tentativas.
- Nova rodada após encontrar a arma correta.

## Tecnologias

- React 19
- TypeScript
- Vite
- Tailwind CSS
